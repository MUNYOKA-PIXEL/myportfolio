# Peter Munyoka Ilunga | Digital Portfolio

A responsive personal portfolio showcasing my background, skills, projects, and contact information.

**Live site:** [munyoka-pixel.github.io/myportfolio](https://munyoka-pixel.github.io/myportfolio/)

## Features

- Home, About, Projects, and Contact sections with shareable links
- Browser Back and Forward support for section navigation
- Light and dark themes, with the selected theme saved in the browser
- Project gallery with category filters
- Skills and tools grouped by category
- Responsive layout and keyboard-accessible controls
- Contact form with client-side validation

## Built with

- HTML5
- CSS3 and [Tailwind CSS](https://tailwindcss.com/) via CDN
- Vanilla JavaScript

## Run locally

This is a static site; it does not require a build step or package installation.

1. Clone or download this repository.
2. Open `index.html` in a browser, or serve the project folder with a local web server such as the VS Code Live Server extension.

An internet connection is needed to load Tailwind CSS from its CDN and to submit the contact form.

## Deployment

The site is deployed with GitHub Pages from this repository. The static files are served directly; no build command is required.
