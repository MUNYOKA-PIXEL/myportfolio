# Peter Munyoka Ilunga | Digital Portfolio

A responsive personal portfolio website showcasing Peter Munyoka Ilunga's background, technical skills, projects, and contact information.

> **GitHub About description:** Responsive personal portfolio built with HTML, CSS, JavaScript, and Tailwind CSS.

## Overview

This portfolio presents a simple, accessible way to explore my work and experience as a software engineering student and web developer. It uses a single-page layout with JavaScript-powered navigation so visitors can move between sections without reloading the page.

## Features

- Responsive layout for mobile, tablet, and desktop screens
- Single-page navigation for Home, About, Projects, and Contact sections
- Filterable project gallery
- Contact form with client-side validation and asynchronous submission
- LinkedIn and GitHub profile links
- Keyboard focus styles for improved accessibility

## Built With

- HTML5
- CSS3
- JavaScript
- Tailwind CSS via CDN

## Projects Included

- Payroll Automation System
- Number Base Converter
- Math and Logic Utilities
- Digital Portfolio SPA

## Run Locally

No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/MUNYOKA-PIXEL/myportfolio.git
   ```

2. Open the project directory.
3. Open `index.html` in a web browser.

For the best local development experience, use the Live Server extension in VS Code.

## Deployment

This project is ready to deploy as a static website using GitHub Pages or any static hosting provider. The live GitHub Pages deployment can be configured from the repository's **Settings > Pages** section.
