My Story

It started in Zambia, back in junior secondary school, when I couldn't stop wondering how everything on a computer actually worked. Then I watched my uncle, a Computer Science graduate, solve real problems with C++, and it clicked: code is a way to build things that help people. Since then I've learned through my degree, self-study and mentorship, and I try to approach every bug with patience (and a bit of stubbornness).

Likes & Inspirations

I'm drawn to how fast tech keeps changing, and to the problem-solving it demands. I think software is less about writing code and more about finding good answers to real problems. Long term, I want to use these skills to help grow Zambia's tech scene.

Away from the keyboard: I swim to clear my head, watch movies and spend time with family, and I'll happily take on a puzzle or help someone think a problem through.

Veterinary Decision Support

Veterinary Clinical Decision Support System

A machine-learning tool that helps vets and livestock officers predict diseases in cattle, sheep and goats from symptoms and vitals. Trained on 32,540 records, it reaches 87.3% accuracy, close to the best the data allows, and it shows how confident it is in each prediction so a person can double-check.

Built with: Python, scikit-learn, Streamlit
